About this video

The Project Context runs as a container and serves a web GUI under /ui. From there you browse your projects, the context engine, MCP tools, RAG settings and collections, and logs. Indexing and storage stay on infrastructure you control.

The written walkthrough is on the Project Context — the web GUI page.
