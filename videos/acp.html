About this video

This video demonstrates how IDEAgent handles cross-project coordination. One agent delegates a task to a peer agent working in a different project repository, and the peer reports back when the work is complete.

How the protocol works is explained in Agent Cross-Project Coordination (ACP) and on the Gateway page.
