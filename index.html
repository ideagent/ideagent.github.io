IDEAgent is a PyCharm coding agent you host yourself. Retrieval and context assembly run on your own machine (see how it stays local), and you choose the model — fully local with Ollama, or your own OpenAI, Anthropic or Google keys. The whole stack — plugin, gateway, context engine and RAG — sends no product-usage telemetry back to us. When you want it, optional gateway redaction can filter detected secrets out of tool and terminal output (unlike cloud-only assistants). Built for developers and teams working on confidential code, including regulated fields like banking and medical software.

Self-hosted, with optional secret redaction before tool output reaches a model and agents that hand work to each other across your projects (ACP).

Core Functionalities

Everything you need for a secure, context-aware AI coding assistant on your own infrastructure.

🛡️

Egress Secret Redaction

Filter API keys, IPs, and emails out of tool and terminal output before they ever reach a cloud LLM.
🤖

Agent Coordination (ACP)

Agents that hand work to each other across your different projects, coordinating complex multi-repository changes.
🔌

MCP Interface

Model Context Protocol integration providing the agent with file-system, terminal, and symbol-aware codebase retrieval.
🧩

PyCharm Plugin

Native JetBrains IDE integration with Chat, Threads, Tasks, and Edits directly in your PyCharm workspace.
⌨️

IDE Integration

Execute tests, fix linter errors, and safely rename symbols using native PyCharm IDE commands driven by the agent. See the full tool list.
