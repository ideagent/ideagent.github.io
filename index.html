The Five Packages

Five focused components that work together to give you a complete, self-hosted AI coding environment.

01

mcp-server

Model Context Protocol Server

The core server implementing the Model Context Protocol. Exposes a well-defined API surface for IDE plugins and external tools to query the context engine, manage tools, and orchestrate AI calls. Runs fully locally.

02

rag-server

Retrieval-Augmented Generation Server

A self-hosted RAG engine that indexes your codebase, documentation, and additional knowledge sources. Retrieves the most relevant context snippets for every AI request — without ever transmitting your full codebase to any third party.

03

gateway

Secure API Gateway

A lightweight proxy between IDE plugins and your AI provider. Enforces local authentication, rate limiting, and request shaping. Your API keys are stored here — never exposed to IDE plugins, never sent anywhere except the AI provider you configure.

04

PyCharm IDEAgent Plugin

JetBrains IDE Integration

The PyCharm plugin that surfaces all IDEAgent capabilities directly in the IDE. Connects to the local MCP server, streams AI responses inline, and provides code completion, refactoring suggestions, and project-aware chat — zero cloud dependency.

05

PyCharm RAG File Watcher Plugin

Real-Time Index Maintenance

A companion PyCharm plugin that watches your project files and keeps the RAG index up to date in the background. When you save a file, rename a class, or add a module, the index updates immediately so the AI always has the freshest view.
